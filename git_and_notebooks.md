Git: This is a tool that allows you to make changes to files of code and track the changes history as well. It is an open source tool.
GitHub: This is a collaborative platform on the internet that allows you to share git projects so others can contribute to it.
Repository: This is a folder of projects that contains various files and folders and tracks all the changes(commits) made.
Commit: It is used to save changes made to the files or folders in your project. It saves it as certain points in the timeline. 
Push: It publishes your changes on your repository to a place other people can access.
Pull: It is used to merge the latest changes on the branches.
Code cell: It is used to write and run codes(proramming language). It provides the output almost immediately, beneath the code cell.
Markdown cell: It is used for documenting or explaining your thoughts. It could function as a header or the role of a comment.
Kernel: It is the engine that runs your code in the code cell of Jupyter notebook during programming.
Restart Kernel: This clears every cell and start afresh
Run all: This runs all the existing code cells from top to bottom or from top to the breakpoint.
